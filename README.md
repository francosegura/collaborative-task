# Collaborative Task App

A mobile application for managing collaborative tasks, built with React Native and Expo.

## Features

- User authentication
- Task management
- Date filtering
- Modern and responsive interface

## Tech Stack

- React Native
- Expo
- TypeScript
- Formik & Yup for validation
- Context API for global state

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   yarn install
   # or
   npm install
   ```
3. Start the development server:
   ```bash
   yarn start
   # or
   npm start
   ```

## Development Setup

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn
- Expo CLI (`npm install -g expo-cli`)
- iOS Simulator (for Mac users) or Android Studio (for Android development)

### Running the App

1. **Install Dependencies**
   ```bash
   # Using yarn
   yarn install

   # Using npm
   npm install
   ```

2. **Start the Development Server**
   ```bash
   # Using yarn
   yarn start

   # Using npm
   npm start
   ```

3. **Choose Your Platform**
   - Press `i` to open in iOS simulator
   - Press `a` to open in Android emulator
   - Scan the QR code with your phone's camera to open in Expo Go app

4. **Development Tips**
   - Use `r` to reload the app
   - Use `m` to toggle the development menu
   - Use `j` to open the debugger

### Testing on Physical Devices

1. **iOS**
   - Install Expo Go from the App Store
   - Scan the QR code with your camera
   - Make sure your phone and computer are on the same network

2. **Android**
   - Install Expo Go from the Play Store
   - Scan the QR code with your camera
   - Make sure your phone and computer are on the same network
